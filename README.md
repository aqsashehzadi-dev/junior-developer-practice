Debugging and Problem Solving
During practice, I have worked through programming and Git-related issues by:
1. Reproducing the problem.
2. Reading the exact error or output.
3. Identifying the relevant part of the code.
4. Making a focused change.
5. Running the program again.
6. Verifying the result.
Examples of issues practiced include:
- Python indentation errors
- ValueError from invalid numeric input
- Incorrect elif structure
- Search and delete logic problems
- Unexpected menu output
- Git working-tree and status checks
